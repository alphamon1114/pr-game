# VARCO 제작 기록

사용자 요청: BenQ ZOWIE XL2540X+, archon M3 600 MINI 블랙, ATK Phantom Verge Blue를 참고한 3D 게임 소품 3종.

## 참고 출처

- 모니터: https://zowie.benq.com/en-us/monitor/xl2540x-plus.html
- 키보드: https://www.preflow.co.kr/product/detail.html?product_no=10776
- 마우스: https://www.atk.store/products/atk-blazing-sky-phantom-hollow-carbon-fiber-composite-wireless-gaming-mouse

공식 사진은 제작 참고에만 사용했으며 원본 파일은 저장소에 포함하지 않는다. `References`에는 VARCO에서 생성한 제작용 이미지가 있다. 제조사 공식 3D 모델이나 정밀 복제품이 아닌 AI 생성 참고 모델이다. 키보드 각인과 배열, 마우스 타공 패턴 등의 세부 차이가 있다.

## 제작 설정

- VARCO Workflow: `4646dc1c-2408-4f66-b1d2-dabb3ace9750`
- EditImage: 제품별 1회, gpt-image-1.5-medium, 1:1.
- Generate3D: 제품별 1개, 삼각형, 2048 텍스처, PBR 켬.
- 목표 폴리곤: 모니터 16,000 / 키보드 24,000 / 마우스 20,000.
- 모니터는 조작 화면 가림을 피하기 위해 차광판과 별도 컨트롤러를 제외했다.
- 모니터의 인터랙티브 OS는 생성 모델에 구워 넣지 않고 Unity 화면 평면에 별도로 표시한다.
- 안내된 예상 생성 비용: 이미지 60 + 3D 600 = 660크레딧. 잔액은 MCP 응답에 제공되지 않음.

## 생성 상태 / 2026-10-06

제작용 이미지 3개는 성공했다. 텍스처·PBR 포함 첫 3D 생성은 세 개 모두 약 12분 후 실패로 반환됐다. 서버 응답에는 아래 task ID 외에 원인이 제공되지 않았다. 실제 크레딧 차감·환불 여부는 확인되지 않았다.

- Monitor: `84a8e551-437b-43e4-8e8c-d674c8d143d8`
- Keyboard: `65669d9c-2aac-4a96-adba-fc25b3c15e20`
- Mouse: `c1f305e2-8c96-41d4-b0c5-b84094325db5`

모니터만 별도 노드 `4921801f-ad70-41e2-8498-5ca3a45ef456`에서 텍스처·PBR 없이 형상 생성으로 재시도했다. 안내 비용은 100크레딧이다. 실패 노드와 성공 이미지는 보존했다.

형상만 생성하는 첫 재시도도 실패했다: task `1fdd1a46-6115-4ff2-b113-9550bcf0d484`. 구체적인 원인은 제공되지 않았다.

## 사용자 요청으로 진행한 두 번째 시도

이번에는 모니터 형상, 모니터 텍스처, 키보드, 마우스 생성이 모두 성공했다. 안내 단가 기준 합계는 600크레딧이며 실제 차감·환불 내역은 MCP에서 확인할 수 없다.

| 결과 | Task |
|---|---|
| 모니터 형상 | `54cd3363-f35a-4d81-bac5-e9d956d2754d` |
| 모니터 텍스처 | `8d977e3f-342b-4e2b-b698-a770cbeba03a` |
| 키보드 | `fd6052b9-319c-4b3d-bb6a-4c3760a28ced` |
| 마우스 / 실제 제품 사진 직접 입력 | `df0330ae-80aa-4f34-ab6b-ae09b5f1a9c4` |

하지만 사용자와 시각 검사에서 키보드 키 사이의 찢어진 면, 울퉁불퉁한 외곽선, 마우스 측면의 자동차 같은 잘못된 구조를 확인했다. 성공 상태와 사용 가능한 품질은 구분하며 이 출력들을 최종 씬에 사용하지 않는다. 원본 다운로드는 무시되는 `Builds/VerificationProject/Assets/Art/Varco`에 보관했다.

Blender로 직접 구성한 대체 모델은 사용자가 너무 단순하다고 판단해 채택하지 않았다. 실험 파일은 `Builds/RejectedHardSurface`에 보관하며 실제 씬에는 적용하지 않았다. 사용자는 마우스와 키보드 모두 VARCO 3D로 실제 형태를 최대한 보존하기를 원한다.

새 마우스 입력은 공식 사선 제품 사진 `3_17e09a45-2687-4a00-994b-46a32d155936.jpg`이다. 겹치는 육각형 선, 중앙 세로 타공, 휠 뒤 잠자리 윤곽, 휠 뒤 버튼 없음을 검사한다. 현재 생성 기록은 `run-status.json`을 참고한다.

형태 보존 시도의 실패 기록:

- 마우스 80k / 2K / PBR: `34bf7192-afad-4303-8d2c-674fe3a7e9bf` 실패.
- 동일 사진 마우스 80k / 2K / PBR 끔: `451ccea8-e81e-4ee9-a9e6-8f3cef04acfa` 실패.
- 키보드 새 입력 / 20k quad / 2K / PBR: `897649f1-9a64-4457-8140-7f52ae4894b3` 실패.

원인이 반환되지 않아 PBR만의 문제로 단정할 수 없다. 후속 시도는 동일 입력으로 형상만 생성하는 마우스 20k tri, 키보드 16k tri였다. 마지막 확인 시 두 작업은 생성 중이었다. 이후 사용자가 Blender MCP로 전환을 요청해 추가 텍스처 작업은 실행하지 않았다. 현재 선택한 모델은 `ArtSource/Blender`의 사진 기반 재구성본이다. 설정과 입력 출처는 `fidelity-retry.json`에 기록한다.
