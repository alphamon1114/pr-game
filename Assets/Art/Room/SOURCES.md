# Room texture sources

The room meshes are original procedural models generated by `ArtSource/Blender/build_room.py`.
The chair is a simplified SIDIZ T50 reference model, not a manufacturer CAD asset.

The following texture maps come from Poly Haven, under CC0:

- Wood Floor: https://polyhaven.com/a/wood_floor
- Wood Table 001: https://polyhaven.com/a/wood_table_001
- White Plaster 02: https://polyhaven.com/a/white_plaster_02
- Fabric Pattern 07: https://polyhaven.com/a/fabric_pattern_07
- License: https://polyhaven.com/license

Maps are stored as albedo.jpg, normal.jpg (OpenGL), roughness.jpg and ao.jpg under Textures/<asset id>.
Unity imports them at up to 1024 pixels, repeats UVs, and applies material-specific tint, normal strength and roughness.
Fabric uses the normal/roughness/AO maps with a plain solid color instead of the plaid albedo.
