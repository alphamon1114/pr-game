# 개발 기록

## 2026-10-06 — 초기 구성

사용자 확정: Unity 새 프로젝트, GitHub 새 공개 저장소. 가상 OS 중심 탐색이며 주변 책상과 모니터가 보인다. 엔딩이나 자기소개서식 순서는 없다.

임시 구현 선택: Unity 6000.6.0f1, UI Toolkit, 도형으로 만든 책상과 모니터, 단일 파일 창. 이름은 PR GAME / 저장소 이름은 pr-game. 실제 개인정보와 링크를 임의로 만들지 않는다.

초기 범위: 바탕화면 폴더 4개, 소개 내용 열기와 닫기, 스크롤, 화면 크기에 따른 배치. 현재 미구현: 파일 계층 탐색, 창 이동, 퍼즐, 발견 상태 저장, 음악 재생, 프로젝트 실행 링크.

## 다음 작업

1. 3D 작업실과 VARCO 장비의 구도·크기·디테일 조정.
2. 배포 가능한 한국어 폰트 도입 및 한국어 UI 적용.
3. 콘텐츠를 코드에서 분리해 파일/폴더 데이터로 관리.
4. 실제 기본 소개, 좋아하는 이유, 대표곡, 프로젝트 이미지와 링크 추가.
5. 첫 파일 탐색 퍼즐과 진행 상태 저장 구현.

## 검증

Unity 새 프로젝트 생성, 초기 씬 생성과 스크립트 컴파일 성공. 배치 실행에서 `PR_GAME_SETUP_OK` 및 정상 종료를 확인했다. 실제 화면과 마우스 조작은 별도 확인이 필요하다.

## 2026-10-06 — 3D 전환 및 VARCO 소품

사용자 확정: 평면 UI 배경 대신 실제 3D 작업실. Start Survey? 구도를 참고하며, 이후 공포 요소를 가볍게 넣는 방향도 논의했다. 자유 탐색과 엔딩 없음은 유지한다.

구현: 3D 방·책상·소품, 모니터 RenderTexture에 UI Toolkit 바탕화면 표시, 실제 스크린 MeshCollider 좌표로 클릭 입력 변환. 우클릭을 누르면 둘러보기, F 집중, Home/Esc 정면, H 분위기 효과 토글. 분위기 효과는 43초 주기의 느린 책상 조명 밝기 변화로 한정했다.

별도 검증 프로젝트에서 컴파일, 모니터 중앙 좌표, 화면 밖 입력 거부, 네 폴더의 포인터 눌림/해제와 닫기, 실제 3D 렌더 캡처를 검사했다. Unity 검색 인덱스 초기화에서 엔진 측 예외가 있었으나 게임 검증은 통과했다. 수동 플레이 감각과 다른 해상도는 후속 확인 대상이다.

VARCO 요청: BenQ ZOWIE XL2540X+, archon M3 600 MINI 블랙, ATK Phantom 블루를 참고한 모델. [제작 기록](../ArtSource/Varco/README.md)에 출처·프롬프트·노드·설정을 기록한다.

VARCO 결과: 제작용 이미지 3개는 성공. 텍스처 포함 3D 3회와 모니터 형상만 생성한 재시도 1회는 모두 실패했다. 상세 원인은 반환되지 않았으며 3D 다운로드 결과가 없어 장비 교체는 미완료다. 임시 장비가 있는 `Desktop3D` 씬은 사용 가능하다. 실패 원인을 확인하기 전까지 추가 유료 생성은 자동 실행하지 않는다.
