# 개발 기록

## 2026-10-06 — 초기 구성

사용자 확정: Unity 새 프로젝트, GitHub 새 공개 저장소. 가상 OS 중심 탐색이며 주변 책상과 모니터가 보인다. 엔딩이나 자기소개서식 순서는 없다.

임시 구현 선택: Unity 6000.6.0f1, UI Toolkit, 도형으로 만든 책상과 모니터, 단일 파일 창. 이름은 PR GAME / 저장소 이름은 pr-game. 실제 개인정보와 링크를 임의로 만들지 않는다.

초기 범위: 바탕화면 폴더 4개, 소개 내용 열기와 닫기, 스크롤, 화면 크기에 따른 배치. 현재 미구현: 파일 계층 탐색, 창 이동, 퍼즐, 발견 상태 저장, 음악 재생, 프로젝트 실행 링크.

## 다음 작업

2. 배포 가능한 한국어 폰트 도입 및 한국어 UI 적용.
3. 콘텐츠를 코드에서 분리해 파일/폴더 데이터로 관리.
4. 실제 기본 소개, 좋아하는 이유, 대표곡, 프로젝트 이미지와 링크 추가.
5. 첫 파일 탐색 퍼즐과 진행 상태 저장 구현.

## 검증

Unity 새 프로젝트 생성, 초기 씬 생성과 스크립트 컴파일 성공. 배치 실행에서 `PR_GAME_SETUP_OK` 및 정상 종료를 확인했다. 실제 화면과 마우스 조작은 별도 확인이 필요하다.
