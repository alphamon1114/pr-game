# 재시작 후 이어갈 작업

2026-10-08에 사용자가 Unity가 멈췄다고 알려 작업 정보와 시안을 저장하고 재시작을 진행했다.

## 마지막으로 구현·검증한 상태

- Unity 6000.6.0f1, `Assets/Scenes/Desktop3D.unity`가 주 작업 씬이다.
- GitHub 공개 저장소 `alphamon1114/pr-game`, `main`의 `ac25f63`까지 구현 변경을 올렸다.
- 실제 인터넷 브라우저는 무료 CEF/CefSharp를 사용한다. 브라우저 시작과 홈 버튼은 네이버, 상단 즐겨찾기에 VARCO 3D Explore가 있다. 기존 즐겨찾기는 유지하고 VARCO를 한 번만 추가한다.
- 파일 탐색기, 메모 파일 저장·더블클릭 실행, 검색, 테마, 알림, 전용 커서, 방/컴퓨터 시점 전환이 구현돼 있다.
- 위 기능들은 별도 검증 프로젝트에서 통과했다. 브라우저 엔진은 `BrowserRuntime/Windows`에 있으며 Git에는 대형 실행 파일 대신 빌드 절차를 관리한다. 자세한 내용은 `BROWSER.md`에 있다.

## 현재 검수 중인 설정 화면

**아직 Unity에 적용하지 않은 시안**이다. 대화에서 검수한 디자인과 실제 구현 상태를 혼동하지 않는다.

- 왼쪽 사용자 영역: 조건희.
- 메뉴: 테마, 브라우저, 소리, 알림, 조작 안내.
- 테마: 실버 + 블루 / 차콜 + 세이지.
- 브라우저: 시작페이지 입력, 즐겨찾기 표시. 기본 주소는 `https://www.naver.com/`, VARCO 즐겨찾기는 `https://3d.varco.ai/explore`.
- 사용자 최신 요청: 소리가 나고, 소리 설정 안에 볼륨 설정이 있으면 좋겠다.
- 최신 시안에는 출력 볼륨 0~100%(초깃값 70%), 볼륨 값을 보존하는 음소거, 누르면 짧은 두 음을 재생하는 테스트 버튼을 넣었다. 자동 재생하지 않는다.
- 시안의 소리 범위는 컴퓨터의 알림·브라우저·시스템 소리다. 방 환경음과 공포 효과음까지 함께 조절할지는 아직 확정하지 않았다.
- 현재 소리 재생은 시안에서만 연결했다. Unity 소리 설정 저장, 실제 오디오 라우팅, 시스템 효과음은 다음 구현 대상이다.
- 시안 원본: `Design/os-settings-review.html`. 일반 브라우저에서 열 수 있는 저장본: `Design/os-settings-preview.html`.

## 다음에 이어갈 순서

1. 프로젝트 재시작 상태를 확인하고 설정/소리 시안을 이어서 검수한다.
2. 사용자가 시안을 적용하도록 요청하면 Unity 설정 메뉴를 구현한다. 기존 메모·파일·테마·방문 기록을 유지하는 방식으로 저장 항목을 추가한다.
3. 게임 진행·퍼즐은 나중에 정한다는 기존 요청을 유지한다. 취향은 직접 소개 목록 대신 검색 기록·파일에서 드러내는 방향이며 엔딩은 따로 두지 않는다.

## 재시작 전 보관

- Unity가 `Reloading Domain`에서 1시간 이상 멈춘 것을 확인했다.
- 로컬 복구 폴더: `Logs/Recovery/20261008-141957/`.
- 씬과 조명 파일, `Temp/__Backupscenes/0.backup`, 사용자 에디터 설정, 게임의 `session-v1.json`과 `.bak`을 별도로 복사했다.
- 복구 데이터와 로그는 Git 제외 영역에만 보관한다. 게임 저장 데이터는 공개 저장소에 올리지 않는다.
- 기존 미추적 파일 `ProjectSettings/PackageManagerSettings.asset`은 별도 백업하고 그대로 둔다.
- 멈춘 에디터의 메모리 안에만 있던 수정 사항은 완전한 저장 여부를 확인할 수 없다. 임시 씬 백업을 원본 씬에 무조건 덮어쓰지 않는다.

## 재시작 결과

- 멈춘 Unity의 저장 단축키 요청도 시간 초과되어, 위 백업 이후 해당 프로젝트의 프로세스와 자식 프로세스만 종료했다.
- 같은 프로젝트를 다시 열어 `PR GAME - Desktop3D` 편집 창으로 돌아왔다. `Reloading Domain` 대기 창은 사라졌다.
- 이번 실행은 기존 검증 환경과 같은 Direct3D 11로 열었다. 프로젝트 렌더링 설정 자체는 변경하지 않았다.
- 재시작 로그는 `Logs/unity-restart-20261008.log`다. 다음 작업은 설정·소리 시안 검수부터 이어간다.
